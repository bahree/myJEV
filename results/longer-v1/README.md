# Reading the longer-study evidence

The official test contains 3,080 examples. Each run has separate training, validation, calibration and test roles. `summary.md` is regenerated by `scripts/summarize_longer_study.py`; it distinguishes released confidence configurations from the matched calibration follow-up.

## Confidence files

- Supervised `evaluation/metrics.json` evaluates the trained scalar correctness head. `posthoc/temperature-metrics.json` evaluates calibrated selected-option probability, the released supervised configuration.
- Exact and sampled RL `evaluation/metrics.json` evaluates the trained confidence-policy expectation.
- **RL `evaluation/scalar-metrics.json` is a diagnostic of an untrained continuation head.** RL does not optimize that scalar head. Its sometimes very high Brier/ECE is not the quality of the released RL confidence estimate and is not a fair competing trained estimator. The historical numeric files remain unchanged.

See [all four matched confidence views](../review-calibration-v1/report.md) and [per-seed contrasts](../review-seeds-v1/report.md). Accepted-case error is undefined when a threshold accepts no examples; zero coverage is not zero error.
